# CNYT 백서

## 기관 파트너 중심의 사업 참여와 디지털 자산 구조

CNYT는 카지노·게이밍 관련 사업과 자산 운용에 참여하는 재단 및 기관 파트너의 관계를 디지털 토큰과 서면계약으로 구성하기 위한 프로젝트입니다. 파트너가 투입한 자본, 배정받은 CNYT, 계약상 보상, 가격 의사결정과 토큰 활용의 관계를 일관되게 정하는 것을 목표로 합니다.

기관 파트너는 재단과 체결한 계약에 따라 CNYT를 배정받고, 약정 보상과 DAO 의사결정, 조건부 CND 전환에 참여합니다. CNYT 보유 자체가 재단의 회사 지분이나 개별 사업자산의 직접 소유권을 부여하지는 않습니다. 파트너의 내부 마케팅·프로모션을 통해 CNYT를 받은 사람에게도 기관 파트너의 계약상 권리가 자동으로 부여되지 않습니다.

이 백서는 CNYT의 사업 구조, 초기 발행 계획, 권리의 범위, 락업과 보상, 가격·거버넌스, 기술 방향과 위험요소를 설명합니다. CND의 상세 설계와 재단의 세부 운영 절차는 별도 문서에서 다룹니다.

**문서 상태:** 검토용 초안

**기술 단계:** TRON 기반 토큰의 로컬 검증 및 Shasta 테스트 준비

이 문서는 메인넷 발행, 외부 보안감사, 실제 모집 또는 계약 체결의 완료를 확인하는 문서가 아닙니다. 계약 당사자의 정식 법인정보와 적용 관할 등은 실제 발행·참여 전 확인사항으로 남아 있습니다.
